## 说明

## 两种生成算法（简要原理）
---
### 1. 混沌游戏（Chaos Game）
- 思路很简单：先确定一个多边形的顶点（例如三角形），然后从一个随机点开始反复“跳”：
  - 每一步随机选一个顶点 `v`
  - 把当前点 `p` 移到中间位置：`p = (p + v) / 2`
  - 把每一步得到的点记录下来，画出来就是点云
- 对三角形来说，反复进行这个过程后，最终会形成 Sierpinski 垫片。
- 特点：实现简单，适合点云显示，效果很明显。五边形和六边形也可以做类似的过程，只是形状和密度会不同。

### 2. 递归细分（Recursive Subdivide）
- 思路是从一个大三角形出发，把它不断分成更小的子三角，然后对每个小三角继续递归。
- 如果在每一层只保留三个角落（不填充中间区域），最终会得到类似 Sierpinski 的镂空结构。
- 具体理解：一开始是一个大三角，按边中点分裂，然后继续分裂每个子三角，直到达到设定的深度 `depth`。
- 特点：结构化、控制参数明确，适合做线框或实体显示；但深度太大��边数会增多，显示会显得密集。

## 交互操作说明
---
- 页面左上角有控制面板，包括：
  - 算法：混沌游戏（3角/5边/6边）或递归细分
  - 渲染模式：点 / 线 / 面
  - 递归深度：控制递归细分的层数
  - 点数：控制混沌游戏生成的点数量
  - 点大小：控制渲染点的大小
  - 配色：橙色 / 蓝色 / 紫色
  - “重新生成”：在修改参数后点击重新生成图形
- 鼠标：
  - 左键拖动：平移视图
  - 滚轮：缩放视图
- 键盘：
  - `1 / 2 / 3`：切换渲染模式（点 / 线 / 面）
  - `空格`：暂停 / 继续混沌游戏的逐点生长动画
- 演示时可以这样讲：
  1. 先展示混沌游戏，点逐渐增加，形成分形结构。
  2. 再切到递归细分，尝试不同 depth，看三角不断细分。
  3. 调整缩放和平移，说明交互功能正常。

## 实现要点（简明说明）
---
- 使用 WebGL2（GLSL ES 3.00）绘制图形。
- 顶点数据通过 `Float32Array` 组织，并通过 `gl.bufferData` 上传到 GPU。
- 混沌游戏：每次迭代生成新的点，并逐步增长到目标数量，实现“点云生长动画”。
- 递归细分：递归输出点 / 边 / 三角数据，根据渲染模式切分为 POINTS / LINES / TRIANGLES。
- 混沌模式默认使用点显示，以避免线条过多看起来非常杂乱。

## 已知限制 / 注意事项
---
- 在某些浏览器或设备上，线宽可能看起来比较细，这是 WebGL 的正常表现。
- 递归深度过大（例如 5 或 6）时，边和三角数量会快速增加，页面可能会变得比较密；建议演示时 depth 控制在 0–4。
- 目前没有实现非常复杂的边去重或索引缓存；这是一个基础版本，适合课程作业展示和演示。

## 结论
---
这个项目主要完成了两件事情：
- 通过随机迭代（混沌游戏）生成 Sierpinski 结构；
- 通过递归细分生成同样类型的镂空分形，并支持多种渲染模式。

它不复杂，但足够说明我掌握了 WebGL 的最小图形程序结构：
- 从应用程序到顶点数据
- 再到缓冲区上传
- 最后调用渲染命令画出图形。

这也是本课程作业所要求的核心知识点之一。
